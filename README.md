# Equity Research Lab

A collection of equity research models, valuation workbooks, and financial analysis projects developed as part of my learning journey in investment research and corporate finance.

This repository documents the analytical process behind evaluating publicly listed companies—from understanding their business models and financial statements to estimating intrinsic value using industry-standard valuation techniques.

The repository will continue to grow as I explore new companies, improve existing models, and expand my knowledge of equity research.

## What you'll find

- Financial Statement Analysis
- Three-Statement Financial Models
- Comparable Company Analysis
- Discounted Cash Flow (DCF) Valuation
- Relative Valuation
- Industry & Competitive Analysis
- ESG Analysis
- Supporting Excel Models
