# Nintendo

This project presents an equity research analysis of Nintendo for merger and acquisition (M&A) Purposes, combining company research with a Discounted Cash Flow (DCF) valuation model.

## Project Objectives

- Understand Nintendo's business model and revenue drivers.
- Estimate intrinsic value using a DCF model.
- Document assumptions and valuation methodology.

## Contents

- 📄 Company Profile
- 📊 DCF Valuation Model

## Skills Demonstrated

- Discounted Cash Flow (DCF) Valuation
- Financial Modeling in Excel
- Equity Research
